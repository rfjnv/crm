# Мост звонков РОП-агента

Отдельный аккаунт Telegram, которому директор и админ звонят обычным звонком. Мост
снимает трубку и соединяет звук с голосовым агентом ElevenLabs (тот же агент, что
в мини-приложении «📞 Позвонить»: русский и узбекский, данные CRM через бэкенд).

Звонить могут только те, кто в `HOS_ALLOWED_IDS` бэкенда и привязан к сотруднику
CRM. Остальным звонок сбрасывается.

## Запуск

1. **Ключ приложения.** Войдите в Telegram под аккаунтом агента на
   [my.telegram.org](https://my.telegram.org) → API development tools → создайте
   приложение. Понадобятся `API ID` и `API Hash`.
2. **Строка сессии.** У себя на компьютере:
   ```
   pip install telethon
   python call-bridge/login.py
   ```
   Введите API ID, API Hash, номер аккаунта агента и код из Telegram. Скрипт напечатает
   строку сессии. Это полный доступ к аккаунту — никому не пересылайте, только в Render.
3. **Секрет моста.** Придумайте длинную случайную строку и поставьте её в
   `ROP_CALL_BRIDGE_SECRET` и у бэкенда `crm-backend`, и у сервиса моста.
4. **Сервис на Render.** Background Worker `rop-call-bridge` (описан в `render.yaml`;
   если Blueprint не синхронизируется — создайте вручную: Python, Root Directory
   `call-bridge`, Build `pip install -r requirements.txt`, Start `python bridge.py`).
   Переменные:
   - `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`
   - `CRM_BACKEND_URL` — адрес бэкенда, например `https://crm-backend-xxxx.onrender.com`
   - `ROP_CALL_BRIDGE_SECRET`
   - `PYTHON_VERSION=3.12.10`
5. **Кто может звонить.** В аккаунте агента: Настройки → Конфиденциальность →
   Звонки → «Мои контакты» и добавьте в контакты директора и админа (или «Все»).

В логах сервиса после запуска: `call bridge is up as @...`. На каждый звонок —
`incoming call from …`, `call … connected`, реплики собеседника и агента.

## Что умеет Белла в этом аккаунте

- **Принимает звонки** от директора и админа.
- **Звонит сама** по просьбе («Белла, позвони мне» в боте или в её личке, `/callme`). Чтобы
  позвонить, ей нужен «знакомый» собеседник: добавьте директора и админа в контакты Беллы
  или напишите ей хотя бы раз.
- **Звонит менеджерам по поручению** («Белла, свяжись с Дилнозой, узнай, как идут продажи» —
  в чате CRM, в боте, у неё в личке или в звонке). Номер берётся из привязанного в CRM
  Telegram менеджера; если Белла его не «знает», добавляет в контакты по служебному телефону
  из CRM. Разговор ведёт отдельный агент ElevenLabs «Белла (звонок менеджеру)» со сводкой по
  менеджеру из CRM. После звонка отчёт приходит тому, кто поручил. Звонки идут по одному:
  аккаунт Telegram держит один разговор за раз.
- **Отвечает в личке** на текст и голосовые — тот же агент и тот же разговор, что в личке
  HOS-бота. Кнопок у обычного аккаунта нет: черновики планов подтверждаются в боте или CRM.

## Как устроено

- `bridge.py` — принимает звонок (py-tgcalls + Telethon), звук звонящего (48 кГц)
  пачками по 100 мс уходит агенту по WebSocket, ответ агента играет в звонок кадрами
  по 10 мс. Перебили агента — недоигранное сбрасывается. Агент попрощался — мост
  доигрывает фразу и кладёт трубку.
- `audio.py` — перевод частот 48 кГц ↔ формат агента (обычно 16 кГц).
- Адрес агента и переменные звонка выдаёт бэкенд:
  `POST /api/public/rop-call/bridge-session` (заголовок `x-bridge-secret`).
