      запроса. Альтернатива: только ссылка и счётчик из `totalsOnly`.
- [ ] Q3. Глобальное правило карточек modern (`glass.css:283–296`: рамка, радиус 24, подъём на hover) на

      карточек `.ant-card` не использует. Альтернатива: снять сразу (риск: карточки сольются с окном там,

      фронтовый)? Дефолт применён: не показывать. Альтернатива: показывать, если живой ответ содержит поле.
- [ ] Q5. Топ-списки при пилюле «День» считаются за месяц (`analyticsPeriodQuery` подменяет day → month,
      `DashboardPage.tsx:192`). Дефолт применён: честно подписывать «за месяц». Альтернатива: добавить

## 2026-10-14 — Дашборд, шаги 1–3

- [x] Q6. `npm run lint` красный ещё до редизайна: 158 ошибок и 18 предупреждений в старом коде
      (`any`, `set-state-in-effect` и т. п.). Гейт «дальше не идти, пока не зелёные» для lint выполнить
      нельзя без правок чужого кода. Дефолт применён: гейт = «ни одной новой проблемы lint, новые и
      изменённые файлы чистые»; build и test — зелёные. Альтернатива: отдельная сессия на чистку lint.
      Ответ (ревью 13.10): принять. Проверено независимо: lint до шагов 1–3 и после — одинаковый (158 ошибок,
      18 предупреждений, те же 56 файлов), новых проблем нет; build собирается, 118 тестов проходят. Гейт в
      брифе §7/§10 и промтах переформулирован: build и test зелёные, lint — без новых проблем относительно
      `main`. Чистка старого lint — отдельная сессия вне редизайна (BACKLOG).
- [x] Q7. Плотность окна `--win-bg` отличается от ТЗ (§3: dark .48, light .42): при этих значениях подписи
      `--c-text-2` над снегом/лесом фото по умолчанию дают 4,37:1 и 3,54:1. Дефолт применён: dark .52,
      light .60 — минимальные значения с контрастом ≥ 4,5:1 (замер по фото с размытием). Альтернатива:
      оставить .48/.42 и поднять непрозрачность `--c-text-2`.
      Ответ (ревью 13.10): тёмная — принять .52. Независимый замер по дефолтному фото: при .48 на голом
      окне 4,92:1, но внутри `Section` (`--fill-1` светлее окна) только 4,42:1; при .52 — 5,18 / 4,63.
      Светлая — .60 не принимать: окно становится молочным, а на голом окне всё равно 4,08:1. Вместо этого
      окно .50, `--c-text-2` light → `rgba(28,26,23,.80)` (и `glassPalette.light.text2`), и для светлой темы
      светлая вуаль на самом фото `rgba(255,255,255,.15)` в `body::before` (аналог `--scene-dim`) — даёт
      4,56:1 на голом окне и 5,32:1 внутри `Section`. Значения в `DASHBOARD.md` §3 и §5 обновлены.
- [x] Q8. Тоны тегов (`data-tone`) перекрывают блок цветных тегов `glass.css` через `!important` — иначе не
      перебить. Дефолт применён: 4 правила с `!important` и комментарием почему. Альтернатива: удалить блок
      цветных тегов раньше (BACKLOG) и обойтись без `!important`.
      Ответ (ревью 13.10): принять. В блоке цветных тегов 51 `!important`, перебить его иначе нельзя. Правило
      лежит в `glass.css`, а не в примитивах; DoD 8 (без `!important`) относится к `components/ui/*.css` и
      выполнен. Удаление блока — BACKLOG после миграции семейств.
