# Вопросы и BACKLOG

Формат: вопрос в одно предложение, уже применённый дефолт, альтернатива. Пользователь ставит галочку и
пишет «Ответ: …». Следующая сессия начинает с разбора ответов.

## 2026-10-13 — Дашборд (из разбора `DASHBOARD.md`)

- [ ] Q1. Доступ к деньгам на дашборде: для уровней `NO_STRATEGIC`/`NONE` денежные плитки не рендерить
      вовсе, а не показывать `•••`? Дефолт применён: не рендерятся (таблица `DASHBOARD.md` §6); `Money`
      на остальных страницах по-прежнему отдаёт `•••`. Альтернатива: `•••` и на дашборде, как в брифе §4.4.
- [ ] Q2. Бухгалтер: секция «Должники» из полного `getDebts({ paymentStatus: 'UNPAID' })` (новый запрос,
      staleTime 5 мин) или ссылка на `/finance/cashbox?tab=debtors` без списка? Дефолт применён: топ-5 из
      запроса. Альтернатива: только ссылка и счётчик из `totalsOnly`.
- [ ] Q3. Глобальное правило карточек modern (`glass.css:283–296`: рамка, радиус 24, подъём на hover) на
      остальных страницах — оставить до их миграции или снять сразу? Дефолт применён: оставить; дашборд
      карточек `.ant-card` не использует. Альтернатива: снять сразу (риск: карточки сольются с окном там,
      где нет другого разделителя).
- [ ] Q4. Склад (`WAREHOUSE`, `WAREHOUSE_MANAGER`): стековый бар этапов сделок не показывать, пока не
      проверено, что `dealsByStatusCounts` реально приходит этим ролям (гейт `DashboardPage.tsx:799`
      фронтовый)? Дефолт применён: не показывать. Альтернатива: показывать, если живой ответ содержит поле.
- [ ] Q5. Топ-списки при пилюле «День» считаются за месяц (`analyticsPeriodQuery` подменяет day → month,
      `DashboardPage.tsx:192`). Дефолт применён: честно подписывать «за месяц». Альтернатива: добавить
      период «день» в API аналитики (BACKLOG).
